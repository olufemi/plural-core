# Update on Chatwoot Live Chat Integration

Hi Marius, quick update on the Plural mobile live-chat support flow.

We have added a backend-owned Chatwoot session endpoint so the mobile app does not need to hold any Chatwoot secret or generate the identity-validation hash.

## Endpoint

```http
GET /profiling/walletmgt/support/chatwoot/session
Authorization: Bearer <customerAccessToken>
```

The app should call this endpoint when the customer opens the support/live-chat screen.

## Sample Response

```json
{
  "statusCode": 200,
  "description": "Live chat session generated successfully",
  "data": {
    "baseUrl": "https://app.chatwoot.com",
    "websiteToken": "CHATWOOT_WEBSITE_TOKEN",
    "locale": "en",
    "colorScheme": "auto",
    "user": {
      "identifier": "customer@example.com",
      "email": "customer@example.com",
      "name": "Customer Name",
      "identifier_hash": "generated_hmac_sha256_hash"
    },
    "customAttributes": {}
  }
}
```

## Mobile App Usage

Install and use the Chatwoot React Native widget:

```bash
yarn add @chatwoot/react-native-widget react-native-webview @react-native-async-storage/async-storage
cd ios && pod install
```

Pass the backend response directly into the widget:

```jsx
<ChatWootWidget
  websiteToken={session.data.websiteToken}
  baseUrl={session.data.baseUrl}
  locale={session.data.locale}
  colorScheme={session.data.colorScheme}
  user={session.data.user}
  customAttributes={session.data.customAttributes}
  isModalVisible={showWidget}
  closeModal={() => setShowWidget(false)}
/>
```

## Important Notes

- `user.identifier` is the customer's email address because email is the stable identifier across Plural's multi-currency wallets and accounts.
- `identifier_hash` is generated by the backend using the Chatwoot HMAC secret.
- The mobile app must never compute or store the Chatwoot HMAC secret.
- For pilot, we are not sending walletId, account number, phone number, or balances into Chatwoot custom attributes.
- If the endpoint returns `503`, live chat is not enabled in backend config.
- If the endpoint returns `500`, Chatwoot config is incomplete on the backend.

## Backend Config Required

```bash
export CHATWOOT_ENABLED=true
export CHATWOOT_BASE_URL="https://app.chatwoot.com"
export CHATWOOT_WEBSITE_TOKEN="<website-channel-token>"
export CHATWOOT_HMAC_SECRET="<identity-validation-hmac-token>"
export CHATWOOT_LOCALE="en"
export CHATWOOT_COLOR_SCHEME="auto"
```
